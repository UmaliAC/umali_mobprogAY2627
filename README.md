## Lab Activity 1: Discussion

In this activity, I integrated the Image widget into the newsfeed_card.dart file to display images in newsfeed posts. I used the hasImage variable to determine whether a post should display an image and the imageUrl variable to provide the image source. If an image URL is unavailable or cannot be loaded, a placeholder is displayed instead. This makes the newsfeed card dynamic because it can display posts with or without images.

## Lab Activity 2: Discussion

In this activity, I implemented a notification screen that displays 20 notifications using a reusable NotificationItem widget. I also added 10 posts to the newsfeed with different numbers of likes, dates, and image settings. Additionally, I updated the AppBar title to change depending on the selected page, added more navigation items, changed the application name to Connect, and updated the color palette to Teal and Cream. These changes improved the design and functionality of the application.
